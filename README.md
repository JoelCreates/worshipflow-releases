# WorshipFlow Studio — releases

This repository only holds WorshipFlow Studio installers and the update feed. It contains no source code.

- **Install:** download the newest `WorshipFlow-Studio-*-Setup.exe` from [Releases](https://github.com/JoelCreates/worshipflow-releases/releases/latest).
- **Updates:** WorshipFlow checks `https://github.com/JoelCreates/worshipflow-releases/releases/latest/download/latest.json` once a day, offers new versions, and checks each download's SHA-256 before installing.
